# 交接简报

更新时间：2026-10-23

## 当前进度

- T01 至 T15 已完成：四项目分层、RTU/TCP 主从站、八功能码、串行轮询、
  点位表、日志统计、趋势图、字节序探测与配置持久化均已实现；无头入口留待二期。
- 应用配置保存在 EXE 同目录 `ModbusHelper.db`；轮询与点位表仅支持读功能码 01 至 04，
  支持多选删除。主从地址基准独立保存，切换显示不改变协议地址。
- 从站初始数据采用主表摘要和四区明细窗口，支持 1000 行浏览、多选删除与输入校验；
  运行时锁定初始配置，手动修改和随机规则更新运行内存，停止重启按配置重建。
- 最新修复：真实编辑重复从站地址后，原校验取消提交，后续切换单元格会触发
  “由于程序无法提交或取消单元格值更改，操作失败”未处理异常。
  现改为非法输入不保存、保留原地址并显示提示；允许切页、删除和关闭，已有重复配置仍禁止启动。
- 同时修复停止从站后摘要列意外变为可编辑，以及普通状态刷新打断地址编辑的问题。
- 本轮补充历史区域体验：请求、响应、从站手动结果和从站报文统一使用“【时间】”格式；
  新记录只在用户原本位于底部时自动滚动，用户滚到旧记录后保持当前位置；轮询最近值表和报文日志表也保留同样的查看位置策略。
- 超时 Tip 与使用手册补充两层超时和重试预算公式：
  `(重试次数 + 1) × 传输层超时 + 重试次数 × 重试间隔`。
- 使用手册与长期事实库已同步；本次复现和修复过程见
  `docs/archive/2026-10-22-从站地址编辑异常修复.md`。
- 最新 Release 已发布：
  `artifacts/ModbusHelper-win-x64/ModbusHelper.WinForms.exe`。

- 界面回归覆盖重复、超范围、非整数和空地址的真实编辑，以及切页、取消、锁定、
  新增、删除、关闭和旧配置修正；默认窗口与 1180x760 小窗口布局检查通过。
- 已检查地址校验截图，提示文字可见，原地址保留。
- 本轮历史自动滚动、【时间】格式、Debug/Release 构建和 COM1/COM2 RTU 自环验证通过。
  历史文本刷新时会保存非底部用户的顶部可见行，不再因重新生成文本而跳到最上方。
- 2026-10-23 复核发现上一版发布目录 EXE 早于滚动修复提交，且底部判断对
  `ScrollBars.Both` 重复扣除了横向滚动条高度，导致到底部时被误判。现已修正底部判断，
  回归测试同时覆盖“底部自动跟随”和“中途查看保持位置”；Release 验证分别确认末条可见、
  中途首行保持，并已重新发布到 `artifacts/ModbusHelper-win-x64/ModbusHelper.WinForms.exe`。
- 2026-10-23 复核发现复用旧发布目录会残留通用版 `System.IO.Ports.dll`，导致双击 EXE
  在启动时于串口枚举处抛出 `PlatformNotSupportedException` 并立即退出。已使用全新发布目录
  重新发布并覆盖标准目录；当前 EXE 可正常显示“Modbus 调试工具”窗口。
- 趋势图已合并为单一数据点提示，数据点集合批量更新并限制鼠标命中检测频率；
  主窗口顶部新增“悬停提示”和“窗口置顶”会话级开关。程序仍允许多开，
  但串口/TCP 监听端口不能重复占用，多个实例默认共享同目录数据库。
- 2026-10-23 本轮代码构建、业务验证和 TCP UI 冒烟均已通过；UI 冒烟新增检查
  `UInt16/Float/ASCII` 数量行为以及写多寄存器不被固定类型锁定。
- 已移除轮询任务表中重复的“显示”列：轮询表只保留“趋势”采集开关，
  趋势页右侧“曲线显示”负责曲线可见性；切换“趋势”后会立即重建趋势曲线列表。
- 本轮新增数据形状约束：每个寄存器为 16 位（2 字节），03/04 读取时
  `Int16/UInt16=1`、`Int32/UInt32/Float=2`、`Double=4`；字符串数量可变，
  写多寄存器数量仍由写入值个数决定。手动读取、轮询任务和点位表会在界面层自动修正固定数量，
  调度器仍会在业务层拒绝不匹配配置。
- 本轮优化刷新体验：历史文本框替换和最近轮询值表更新禁止中间重绘；
  历史区域只在原本位于底部时纵向跟随，水平滚动位置始终保持。
- 复现轮询表仍可把 `03 + UInt16` 改成数量 2 后，已将固定类型数量列改为不可编辑；
  旧配置进入该单元格时会自动归一化，UI 冒烟已覆盖该场景。
