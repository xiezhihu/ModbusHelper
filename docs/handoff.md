# 交接简报

更新时间：2026-10-24

## 当前进度

- T01 至 T15 已完成：四项目分层、RTU/TCP 主从站、八功能码、串行轮询、
  点位表、日志统计、趋势图、字节序探测与配置持久化均已实现；无头入口留待二期。
- 应用配置保存在 EXE 同目录 `ModbusHelper.db`；轮询与点位表仅支持读功能码 01 至 04，
  支持多选删除。主从地址基准独立保存，切换显示不改变协议地址。
- 从站初始数据采用主表摘要和四区明细窗口，支持 1000 行浏览、多选删除与输入校验。
  运行时禁止编辑和增删，但仍可选中并点击“查看当前数据”或双击查看四区只读明细。
- 上表和只读明细已改为数据变化事件同步：手动、随机和主站写入由通信层统一通知，
  业务层转发，界面合并连续通知后异步更新，不再每 0.5 秒查询。包含新增地址，
  保留滚动与选中位置。停止后上表恢复初始配置，临时值不回写数据库。
- 已修复非法从站地址导致切换单元格异常：保留原地址并显示提示，不阻止切页、删除或关闭；
  旧配置存在重复地址时仍拒绝启动。
- 03/04 固定数值类型的读取数量自动确定且不可编辑，数据类型切换后立即刷新数量格；
  ASCII/UTF-8 数量可变，写多寄存器数量由写入值个数决定。
- 轮询表只保留“趋势”采集开关，曲线可见性统一在趋势页控制；
  主窗口支持会话级悬停提示和窗口置顶，仍允许多开。
- 运行中修改“趋势”会即时同步到调度器，从下一次成功读取开始采集；
  取消后轮询继续，再次勾选可恢复，不需要停止任务或重新连接。
- 历史文本框追加数据时闪烁已修复：请求、响应、从站报文及手动结果统一增量追加，
  超限只删除最旧前缀，客户区在内存中完成绘制后一次呈现。
  原本在底部时纵向跟随；查看旧记录时保留未过期记录的位置、选中文字和实际水平位置。
- 已提供 `installer/ModbusHelper.iss`，可自行使用 Inno Setup 编译安装包。
- 定时机制审查完成：应用显式定时器仅剩主窗口的 200 毫秒批量刷新；
  轮询间隔、随机数据周期、通信超时和停止等待保留。具体用途见本轮归档。
- 使用手册、长期事实库已同步；本次过程见
  `docs/archive/2026-10-24-从站数据事件同步与定时任务审查.md`。
- 最新 Release 已发布并验证启动：
  `artifacts/publish-win-x64-20261024-2/ModbusHelper.WinForms.exe`（界面程序集：2026-10-24 17:24:40）。
