  手动读写字段标签改为填充式并加宽，轮询表和点位表改为固定可读列宽、名称列按剩余空间伸展，
  窄窗口通过横向滚动保留完整功能码和字节序文本。

  轮询任务表启用整行多选，支持 Ctrl/Shift 选中多条，删除、启动选中、停止选中按全部选中任务执行。
- 已完成本轮文字裁切整改：主窗体标题、副标题和页签改为首选高度布局；字段表行高改为自动高度；
  轮询表、点位表、从站表和日志表统一按 DPI 设置行高与表头高度；数据类型、字节序列宽加宽，
  下拉编辑框延迟设置最小展开宽度，`ASCII 字符串`、`UTF-8 字符串` 等长文本可完整查看；
  从站串口格式中的“数据位/校验”标签改为填充式对齐，异常规则表采用紧凑列宽避免横向挤出。
- UI 冒烟新增数据类型下拉宽度检查；当前 `COM1/COM2` RTU 自环和 17 项业务验证均通过。
- 已为连接、手动读写、轮询、从站模拟、趋势图、报文日志、点位表和字节序探测的关键控件增加悬停 Tip，
  说明地址基准、两层超时、字节序、多选批量操作、异常注入和趋势缓冲等容易误解的行为。
- 连接页请求区域已改为最近 200 条主站请求历史，格式为“时间戳：十六进制报文”，
  每个重试帧单独显示；连接参数校验会提示应用层应答超时不足以完成全部配置重试的情况。
- 连接页响应区域已改为最近 200 条主站响应历史，格式为“时间戳：十六进制报文”，
  每个轮询或重试响应单独显示；解析结果区域仍只显示当前操作的解析值。
- 配置已切换为 EXE 同目录 `ModbusHelper.db`：连接、轮询、点位、解析、趋势容量和从站配置持久化，
  旧 JSON 首次启动自动迁移；轮询/点位表功能码仅提供 01 至 04，点位表支持 Ctrl/Shift 多选删除。
- 已收紧点位表默认列宽，常用窗口下“趋势”勾选列无需横向滚动即可看到；UI 冒烟会检查该列完整可见。
- 已澄清从站模拟交互：单元表直接编辑“从站地址”（即 UnitID）；四种存储区按“地址=值”显示；手动编辑地址跟随当前基准，
  并随存储区在 40001、30001、1、10001 等设备手册地址间换算；默认 UnitID 与已配置单元同步。
- 从站模拟页的初始数据表已改为“模拟设备与初始数据”，列名直接标出 01/02/03/04 功能码；
  表格 Tip 说明从站地址、功能码与“地址=值”格式；初始数据和运行时手动修改的生效时机已补入手册。
- 从站初始数据表已改为“主表摘要 + 明细编辑窗口”：主表只显示每个存储区的地址数量，
  双击存储区单元格或点击“编辑初始数据”后按地址逐行查看、增删、清空和应用；运行时继续锁定编辑入口。
  明细窗口支持四区标签页、Ctrl/Shift 多选删除、十进制或 0x 十六进制值输入、重复地址和非法值提示，
  并在小窗口和 1000 行数据下保持可浏览。
- 异常注入数量现在定义连续地址范围，按请求范围与规则范围重叠判定；从站报文历史明确显示完整时间戳、
  收发方向、十六进制帧和解析含义。TCP/RTU 异常范围和 UI 地址换算自环验证通过。
- RTU UI 自环曾因临时配置继承了 5 位数据位而出现 `0x2A` 被截成 `0x0A` 的 CRC 错误；
  现已固定冒烟测试使用主从一致的 9600-8N1，并在非 8 位配置时给出警告和悬停提示。
- 主站 RTU 操作在串行锁内清理残留输入，主从启动时清理输入和输出缓冲；TCP/RTU UI 自环、
  17 项业务验证和分层检查均已重新通过。
- 为避免把主站误解为“模拟器”，连接页签已更名为“主站连接与读写”，
  “从站模拟”继续作为模拟设备入口。
- 从站初始值表使用 `地址 = 值` 格式；手动修改仅改运行内存，停止后重启恢复初始值。
  操作历史保留最近 100 条并分别标记读取、写入和错误；初始值表、手动区和异常规则的提示已补清。
- 从站页在窄窗口下允许纵向滚动，确保 RTU 参数区较高时初始值表仍有可用空间；
  UI 冒烟验证了表格首行可见、地址基准格式切换、初始值/临时值差异、重启恢复及 100 条历史上限。
- 从站启动中和运行时锁定初始数据表及新增/删除单元操作，停止后恢复编辑；
  UI 冒烟覆盖锁定、解锁和修改初始值后重启生效。
- 从站模拟新增多规则随机数据：可配置“启动时随机”“运行中随机”，并可在停止状态将规则结果生成到初始数据表；
  规则持久化到 EXE 同目录数据库，运行随机任务在通信层后台执行，不操作 UI。
- 从站页面根布局已改为自适应：大窗口填充客户区并按比例分配上下区域，小窗口切换为可滚动最小高度，
  避免页面底部空白和表格首行裁切。
- 从站监听区新增独立“从站地址基准”；初始值表、异常规则和运行中手动读写使用本页基准，
  主站读写、轮询和点位表继续使用主站基准，两套设置分别保存到 EXE 同目录数据库。
- 基准切换保持原协议地址和运行内存；无效初始值会拒绝切换，避免部分换算。旧配置缺少从站基准字段时默认 0 基。
- 新增验证覆盖主站 0 基与从站 1 基自环、四区地址换算、规则编辑换算、无效输入回滚、运行中切换及重启后独立恢复；
  TCP 与 COM1/COM2 RTU UI 自环均通过。最终业务验证 18 项全部通过，先前一次串口占用在复跑时已消失。
- 本轮 Release 发布输出：`artifacts/ModbusHelper-win-x64/ModbusHelper.WinForms.exe`；
  TCP 与 `COM1/COM2` RTU UI 自环、18 项业务验证、格式、构建和分层检查通过。
