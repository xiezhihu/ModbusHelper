- 已建立 `Core`、`Communication`、`Business`、`WinForms` 四项目分层。
- 已固定 NModbus 3.0.83、NModbus.Serial 3.0.83、WinForms.DataVisualization 1.10.2。
- 已预留 `--headless` 入口，UI 依赖装配与主窗体骨架已建立。
- T01 配置持久化、T02 参数校验与地址基准、T03 异常码映射已完成。
- 已建立无第三方测试框架的验证控制台，覆盖配置、边界、地址和异常基础用例。
- T04 至 T11 已实现：RTU/TCP 主站、八个功能码、完整帧采集、日志统计、
  多任务串行轮询、TCP 从站、多 UnitID 和异常注入。
- TCP 自环验证已覆盖 125/126 边界、读写回环、异常 02、重连和并行轮询。
- T12 至 T15 已实现：五页签主界面、点位表、日志导出、五曲线趋势图和字节序探测。
- UI 冒烟已验证自环连接、手动读取、五曲线、报文日志和探测窗体渲染。
- RTU `COM1/COM2` 自环已完成，覆盖 125/126 边界、读写、异常 02、断线轮询停止和端口重复打开。
- Release 构建、分层扫描、16 项业务验证和 UI 冒烟均通过。
- 已完成界面布局整改：连接页参数分组自适应并可滚动，读写结果区使用百分比高度；
  从站页重排监听、单元、异常规则和手动模拟区域；点位表与探测窗体缩短列标题并调整尺寸。
- UI 冒烟新增默认窗口和 1180x760 小窗口布局检查，自动检测可见控件零尺寸、按钮与标签文字裁切、
  分组标题空间不足和同级控件重叠，并覆盖字节序探测与点位表窗体。
- 根据现场截图继续整改：连接页移除大块空白，连接按钮与短状态同行显示，地址基准在最小窗口保持可见；
  手动读写字段标签改为填充式并加宽，轮询表和点位表改为固定可读列宽、名称列按剩余空间伸展，
  窄窗口通过横向滚动保留完整功能码和字节序文本。
- 继续修复高 DPI 现场截图：从站监听区不再使用固定高度，RTU/TCP 参数按首选高度分配；
  轮询任务表启用整行多选，支持 Ctrl/Shift 选中多条，删除、启动选中、停止选中按全部选中任务执行。
- 已完成本轮文字裁切整改：主窗体标题、副标题和页签改为首选高度布局；字段表行高改为自动高度；
  轮询表、点位表、从站表和日志表统一按 DPI 设置行高与表头高度；数据类型、字节序列宽加宽，
  下拉编辑框延迟设置最小展开宽度，`ASCII 字符串`、`UTF-8 字符串` 等长文本可完整查看；
  从站串口格式中的“数据位/校验”标签改为填充式对齐，异常规则表采用紧凑列宽避免横向挤出。
- UI 冒烟新增数据类型下拉宽度检查；当前 `COM1/COM2` RTU 自环和 16 项业务验证均通过。
- 已为连接、手动读写、轮询、从站模拟、趋势图、报文日志、点位表和字节序探测的关键控件增加悬停 Tip，
  说明地址基准、两层超时、字节序、多选批量操作、异常注入和趋势缓冲等容易误解的行为。
