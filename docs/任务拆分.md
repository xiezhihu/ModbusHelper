# 开发任务拆分

## 推进原则

- 一个任务形成可独立验收的完整切片，按小粒度提交。
- 先稳定配置、异常、参数和连接生命周期，再接入主站读写与界面。
- 通信层和业务层先行，WinForms 只做最后装配，避免把协议逻辑写进事件处理器。
- 每个任务同时补齐边界验证，不把测试集中拖到最后。

## 任务总表

| 编号 | 任务 | 主要交付物 | 验收重点 | 前置任务 |
| --- | --- | --- | --- | --- |
| T00 | 仓库与工程骨架 | Git、解决方案、四项目分层、入口预留、任务文档 | 全解决方案可构建，底层无 UI 引用 | 无 |
| T01 | 配置模型与持久化 | 纯 POCO 配置、`ConfigVersion`、字符串枚举、JSON 存储 | 保存加载往返一致，运行时状态不落盘，不自动连接或轮询 | T00 |
| T02 | 参数校验与地址基准 | UnitID、数量、地址、写入长度校验，0 基与 1 基换算 | 125 个寄存器通过，126 个给出明确错误，`40001` 转为协议地址 0 | T00 |
| T03 | 自定义异常与异常码 | `ModbusCommunicationException`、异常码中文表、NModbus 异常转换 | 01 至 0B 均有中文含义，05 提示后续轮询读取 | T00 |
| T04 | 连接生命周期 | RTU/TCP 连接、两层超时、状态事件、重复重连、资源释放 | 区分端口占用、参数错误和超时；断开后端口可再次打开 | T01、T03 |
| T05 | 主站单次读写 | 01、02、03、04、05、06、0F、10 功能码封装 | 八个功能码可用，单实例调用串行，广播写不等待响应 | T02、T03、T04 |
| T06 | 原始报文采集 | 串口与网络流的帧采集、十六进制转换、方向标记 | 每次请求和响应均有原始帧；主站与从站日志可按角色区分 | T04 |
| T07 | 数据编解码 | Int16、UInt16、Int32、UInt32、Float、Double、ASCII、UTF-8 | 四种字节序往返一致；术语统一为字序和寄存器内字节序 | T02 |
| T08 | 日志与统计 | 普通类型日志、级别、过滤、搜索、RFC 4180 导出、统计模型 | 中文 CSV 带 BOM 可被 Excel 正确打开；暂停采集不丢已有记录 | T03、T06 |
| T09 | 轮询调度 | 多任务配置、独立启停、单连接串行队列、失败策略 | 同主站任务不并发；停一条不影响其他；断线自动停止并通知 | T05、T08 |
| T10 | 从站存储与网络 | 多 UnitID 从站、独立存储、RTU/TCP 监听、初始值修改 | NModbus 3.0.x 从站 API 正确；RTU 分隔交给传输层 | T04、T07 |
| T11 | 从站异常注入 | 按 UnitID、功能码和地址配置强制异常码 | 异常 02 能从模拟器传到主站并显示中文含义 | T10 |
| T12 | 主窗体和手动调试 | 连接面板、读写面板、地址基准、结果和状态显示 | UI 无直接 Modbus 调用；连接与读写失败显示可读原因 | T05、T06、T09 |
| T13 | 轮询任务与日志界面 | 任务列表、点位表、日志表格、过滤和导出操作 | 后台线程不直接操作控件；任务状态与运行状态一致 | T08、T09、T12 |
| T14 | 趋势图 | SPSC 环形缓冲区、200 毫秒 UI 定时器、多曲线、暂停、窗口、PNG | 100 毫秒轮询和 5 条曲线时 UI 可交互，容量固定不持续增长 | T09、T13 |
| T15 | 字节序探测 | 读取 2 或 4 个寄存器、四种解析、范围高亮、一键应用 | 同一原始数据四种结果正确，推荐规则清晰并有手册提示 | T07、T12 |
| T16 | 自环与验收加固 | TCP/RTU 自环脚本、异常与断线专项验证、资源与内存检查 | 覆盖全部验收标准，长时间轮询无泄漏、无报文错乱 | T09 至 T15 |

## 建议提交切片

- T01：配置模型与 JSON 存储可拆为两次提交。
- T04：连接抽象、RTU、TCP 分别提交，避免一次审查过大。
- T05：按读取、单写、多写分批提交。
- T08：日志模型、导出、统计分别提交。
- T10：从站存储、TCP 从站、RTU 从站分别提交。
- T12 至 T15：每个可操作界面或独立工具独立提交。

## 关键路径

```text
T00 -> T01 -> T04 -> T05 -> T09 -> T12 -> T13 -> T14
          \-> T03 -> T06 -> T08 /
T00 -> T02 -> T07 -> T10 -> T11 -> T16
                   \-> T15
```
