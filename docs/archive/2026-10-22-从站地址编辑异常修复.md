# 从站地址编辑异常修复记录

日期：2026-10-22

## 问题与复现

用户反馈界面弹出未处理异常：“由于程序无法提交或取消单元格值更改，操作失败。”
通过实际表格编辑控件输入重复从站地址，结束编辑并切换当前单元格，复现相同异常。
原有测试直接修改绑定值，未覆盖真实输入和焦点切换。

原因是从站地址的单元格验证通过取消事件阻止提交，表格仍处于无效编辑状态；
后续设置当前单元格时无法完成原单元格的提交或取消。

## 修复行为

- 在单元格解析阶段检查重复、范围、整数格式和空值；无效输入使用原值完成提交，
  在工具栏下及单元格错误提示中说明“本次修改未保存”。
- 保留启动前的配置整体校验；旧配置中已有的重复地址仍须修正或删除后才能启动。
- 新增单元前提交当前有效地址，按提交后的配置分配未使用地址；删除单元前取消当前草稿。
- 普通状态刷新不打断地址编辑；仅实际进入运行锁定时结束编辑。
- 回归额外发现停止从站后整表解除只读会清除摘要列的只读状态，已显式恢复列约束。

## 验证记录

- 修复前新增真实编辑回归测试，确实复现用户截图中的相同异常。
- 修复后 Debug TCP 和 Release COM1/COM2 RTU 界面自环通过。
- 回归覆盖重复、0、248、256、非整数、空输入、切页、取消、锁定、状态刷新、
  新增、删除、已有重复配置修正和存在无效草稿时关闭窗体。
- 默认窗口与 1180x760 小窗口布局检查通过；地址校验提示截图已人工查看。
- 18 项业务验证全部通过，Release 构建、格式和界面依赖边界检查通过。
