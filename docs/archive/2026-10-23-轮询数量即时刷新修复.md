# 轮询数量即时刷新修复

## 问题与原因

切换轮询任务的数据类型后，数量仍显示旧值，点击数量格才更新。
原处理逻辑已修改配置对象，但配置模型为普通对象，没有发出属性变化通知；
绑定表格未重绘关联的数量格。点位表存在同样的问题。

## 修改

- 数量归一化后，仅在数量改变时刷新对应绑定项，让数量格立即显示正确值，减少无变化重绘。
- 保留数据类型与数量：固定数值类型锁定数量，字符串和位读取仍可配置数量。
- 同步使用说明、软件使用手册、长期事实库和交接简报。

## 验证

- 回归测试在类型格保持焦点，连续切换类型，检查数量格实际绘制的文字。
- 轮询覆盖 `UInt16=1`、`Float=2`、`Double=4`，点位表覆盖 `Float=2`、`UInt16=1`。
- 临时回退轮询绑定刷新后，测试报告“配置值=1，绘制值=未重绘”；恢复后通过。
- Release 构建零警告、零错误；业务验证通过 18 项。
- TCP 界面自环、大小窗口检查、格式检查和分层检查通过。
